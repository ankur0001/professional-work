# The Java Story — Narrative Review Pack

One markdown file per video with **descriptive, example-driven instructor narration**
(target **4–15 minutes**, aim ~10–12) plus handbook source attribution.

After review feedback, scripts were rewritten so concepts are explained in context:
why they exist, how they work, walked-through Java examples, common misunderstandings,
and a natural bridge to the next topic — not short disconnected definitions.

Style guide: [`EXPANSION_STYLE.md`](EXPANSION_STYLE.md)

## How to review

1. Start with [`episodes/ep04_variables-and-data-types.md`](episodes/ep04_variables-and-data-types.md) (matches the requested variables style).
2. Also read [`episodes/ep01_why-java-exists-introduction-to-java.md`](episodes/ep01_why-java-exists-introduction-to-java.md) and [`episodes/ep07_methods.md`](episodes/ep07_methods.md).
3. Spot-check any later `epXX_*.md`.

## Technique (from ChatGPT refinement)

See [`EXPANSION_STYLE.md`](EXPANSION_STYLE.md).

* Use EP01 / EP04 / EP07 as the **quality benchmark**
* Do **not** copy sentence patterns, paragraph structures, analogies, or transition phrases
* Extract the underlying teaching technique
* Same **level** of continuity, depth, integrated examples, code walkthrough, natural questions, and cause-and-effect reasoning — not identical sound
* Concepts must feel necessary from what the learner just encountered
* Examples integrated; code with context + after-walkthrough + back to the problem
* Progressive depth; defer later-topic detail with curiosity
* Feel like thinking with the learner, not reading Java facts

**Final test:** If you remove the headings, does it still sound like one person naturally teaching for ~10 minutes?

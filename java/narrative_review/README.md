## Technique

See [`EXPANSION_STYLE.md`](EXPANSION_STYLE.md).

Use EP01 / EP04 / EP07 as the **quality benchmark**, but do **not** copy their sentence patterns, paragraph structures, analogies, or transition phrases.

Extract the underlying teaching technique so every episode has the same level of continuity, depth, integrated examples, code walkthrough, natural questions, and cause-and-effect reasoning.

**Final test:** If you remove the headings, does it still sound like one person naturally teaching for ~10 minutes?

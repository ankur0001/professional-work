• JPA entities move through named states.
• **Transient**: a new CargoItem(...) that the persistence context has never seen — no row yet.
• **Managed**: loaded or persisted inside an open persistence context; dirty checking applies.
• **Detached**: the context closed (typically when the transaction/request ended) but the object still sits…
• **Removed**: marked for deletion on flush.
• Controller calls a transactional service.
• …and more

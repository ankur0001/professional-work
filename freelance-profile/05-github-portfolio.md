## Repos to create (pick 2–3 — even small demos help)

### 1. `spring-kafka-microservices-demo` (HIGH PRIORITY)

**Purpose:** Prove Kafka + Spring Boot + microservices skills

**Minimum scope (1 weekend):**
- Order service + notification service
- Kafka topic for events
- REST API + simple Docker Compose (Kafka + apps)
- README with architecture diagram (ASCII or image)

**README sections:**
- Architecture overview
- How to run locally
- Design decisions (why Kafka, partitioning, etc.)

### 2. `solution-architect-portfolio`

- Host the HTML portfolio (`freelance-profile/portfolio/index.html`)
- Enable GitHub Pages: Settings → Pages → main branch

### 3. `aws-spring-boot-starter` (optional)

- Spring Boot on AWS: ECS or EKS deploy notes
- Terraform or CloudFormation snippets
- CI/CD with GitHub Actions

# Digital profile audit checklist

Score yourself: ✅ done | ⚠️ partial | ❌ missing

## LinkedIn

- [ ] Custom headline (not default job title only)
- [ ] About section: 1,200–2,000 chars with keywords + CTA
- [ ] Profile photo: professional, face visible
- [ ] Banner image: architecture/cloud theme (optional but helps)
- [ ] Open to Work → **Contract / Freelance** enabled
- [ ] Services: Solution Architecture, Java, Cloud, Kafka (if available in your region)
- [ ] Skills: top 5 match headline (Java, Spring Boot, Microservices, AWS, Kafka)
- [ ] Featured: GitHub, portfolio link, or PDF case study
- [ ] Experience bullets: metrics (%, latency, uptime, team size)
- [ ] Recommendations: at least 2 (ask former managers/colleagues)

## GitHub

- [ ] Profile README with role + stack + contact
- [ ] Pin 2–4 repos (even small demos count)
- [ ] At least one repo: Spring Boot + Kafka or microservices demo
- [ ] Consistent commit activity (or note "consulting work is private")

## Upwork

- [ ] Professional title ≤ 70 chars
- [ ] Overview: problem → expertise → domains → CTA
- [ ] Hourly rate set (start competitive, raise after reviews)
- [ ] Portfolio: 2–3 case studies (can be anonymized)
- [ ] Skills tags: 15 max, prioritize architect keywords
- [ ] Availability calendar accurate
- [ ] ID verification completed
- [ ] Profile photo matches LinkedIn

## freelancermap / EU B2B

- [ ] English profile + skills matrix filled
- [ ] Remote / on-site preference set
- [ ] B2B availability and workload (e.g. 100%)
- [ ] Keywords: Kafka, Spring Boot, AWS, Banking

## General

- [ ] One professional email on all platforms
- [ ] Same headline theme everywhere (consistency)
- [ ] No empty sections
- [ ] Spell-check and remove internal company names if contract forbids

## Photo & trust signals

Clients hire senior architects who look credible and communicate clearly:

- Video intro on Upwork (60 sec) — optional but strong
- Link to portfolio page
- Response time < 24h on platform messages

# GitHub Pages

This folder publishes your portfolio at:

**https://ankur0001.github.io/professional-work/**

## Enable on GitHub (one time)

1. Open https://github.com/ankur0001/professional-work/settings/pages
2. **Build and deployment → Source:** Deploy from branch
3. **Branch:** `main` → folder **`/docs`**
4. Save — site live in 1–2 minutes

Edit the source file: `all-work/freelance-profile/portfolio/index.html`  
Then copy to `docs/index.html` before commit (or ask agent to sync).

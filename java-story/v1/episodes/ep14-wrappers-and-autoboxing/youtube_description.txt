The Java Story — Episode 14: Wrappers and Autoboxing
Original cut.

The Java Story is a structured series that teaches Java from first principles through modern production practice — one clear episode at a time.

In this episode:
• Enums gave us type-safe states
• int is a primitive
• Autoboxing hides the conversion — and can hide costs and crashes.
• Today we make that invisible work visible.
• Get this mental model right — collections depend on it.
• Lists and maps need objects — wrappers bridge that gap.
• …and more

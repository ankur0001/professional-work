# The Java Story

85-episode YouTube-style Java series. Each episode folder is a **YouTube upload pack**.

## Per-episode pack (v1 and v2)

```
java-story/{v1|v2}/episodes/epNN-<slug>/
├── title.txt                 ← YouTube title
├── youtube_description.txt   ← description + timestamps
├── chapters.txt              ← timestamps only
├── tags.txt                  ← suggested tags
├── thumbnail.jpg             ← upload thumbnail
├── Java_Episode_NN_*.mp4     ← clean video
├── Java_Episode_NN_*_CAPTIONED.mp4
├── Java_Episode_NN.srt       ← captions
├── narration.md              ← narration / transcript
└── README.md                 ← checklist + links
```

v2 also includes `*_SOURCE.md` (build provenance).

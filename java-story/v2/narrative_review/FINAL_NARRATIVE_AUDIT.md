## Episodes requiring attention

Only episodes with **Overall = MINOR ISSUE** or **MAJOR ISSUE** (none major overall).

### EP05 — Operators
**Necessity (MINOR).** Bitwise operators arrive as “one more family” after the gradebook / comparison thread, without a problem that forced them. The rest of the operator story is necessity-driven.

### EP06 — Control Flow
**Necessity (MINOR).** Pattern matching on a general `Object` lands before OOP has taught type hierarchies. Useful as a preview, but less necessary than the if/switch/loop core of the lesson.

### EP10 — Object-Oriented Programming
**Explanation (MINOR).** `equals` / `hashCode` is asserted as contract lore without a concrete failure walkthrough, so that beat is thinner than encapsulation, composition, and polymorphism in the same episode.

### EP14 — Wrappers and Autoboxing
**Filler / Bridge (MINOR).** A late “nullable `Integer`” habit tip blurs the closing pressure, so the handoff into generics is slightly less clean than the rest of the lesson.

### EP18 — Records
**Filler (MINOR).** Mid-lesson sealed foreshadowing and “opportunistic adoption” meta-advice briefly interrupt continuous problem-solving before the sealed-classes bridge.

### EP20 — Modules and JPMS
**Bridge (MINOR).** The ending pivots from JPMS encapsulation to “everyday programs need lists,” which reads more like the start of a collections unit than pressure created by modules themselves.

### EP21 — Lists
**Continuity (MINOR).** Opening continuity leans on modules as scenery for the collections arc; after that, the list narration is solid. Soft break at the JPMS → collections unit boundary (paired with EP20).

### EP29 — Parallel Streams
**Bridge (MAJOR column / MINOR overall).** Body teaching is strong, but the ending stitches to Optional with syllabus glue: absence/`Optional` is not a pressure created by parallel streams. Breaks EP29 → EP30 necessity for the next topic.

### EP30 — Optional
**Continuity / Bridge (MINOR).** Opens as a chapter reset after parallelism, then bridges to `java.time` with a thin “same class of mistake” analogy. The Optional lesson itself is solid; the series join points on both sides are soft.

### EP39 — Explicit Locks
**Explanation / Example/Code (MINOR).** `Condition` is billed as a reason to leave `synchronized`, yet it is mostly declared without an `await` / `signal` walkthrough, so a featured idea is undersold.

### EP44 — Synchronizers
**Example/Code / Filler (MINOR).** Latch and semaphore are taught well; `CyclicBarrier` is contrast-only with no code, and a late checklist beat is mildly formulaic.

### EP49 — Deadlocks
**Continuity / Filler (MINOR).** Opening surveys locks/queues/phases and does not acknowledge the prior ThreadLocal episode’s ambient-state thread (EP48’s lock-cycle teaser does help). Mild end checklist restates rules already given.

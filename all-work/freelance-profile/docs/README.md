## GitHub Pages note

GitHub’s built-in “Deploy from branch → `/docs`” option only accepts a
**repository-root** `/docs` folder. After this move, either:

1. Use **GitHub Actions** to publish from `all-work/freelance-profile/docs`, or
2. Copy/symlink this folder back to repo-root `docs/` when you want the simple Pages setting.

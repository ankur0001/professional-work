# Platform setup guide — who logs in where

## How we work together

```
YOU fill intake (08-PROFILE_INTAKE)  →  I generate all text + GitHub files
YOU log in (5–15 min per site)       →  paste my text → Save
YOU upload photo once per platform   →  done
```

**You never need to give me passwords.**

---

## Per platform

### GitHub — I can do most of this for you

| What | Who |
|------|-----|
| Portfolio HTML, README, Pages config | **Agent** (push to repo) |
| Profile photo | **You** (github.com → Settings → Profile) |
| Pin repositories | **You** (or tell me which repos to document) |

**Needed from you:** Confirm repo names in intake §13. No credentials.

## Minimum send list (quick start)

If intake is too long, send at least:

1. Full name  
2. Email + phone  
3. City, country, timezone  
4. Rates (min + target USD/hr)  
5. Availability (hrs/week, start date)  
6. Last 3 jobs: company, title, dates, 3 bullets each with metrics  
7. 3 project highlights with outcomes  
8. Education  
9. Certifications  
10. Resume paste or PDF  

That is enough for 90% of profile content.

---

## Security reminder

- Credentials in chat can be leaked, logged, or misused.
- Upwork/LinkedIn use 2FA — automated login usually fails.
- **Best practice:** you own accounts; agent owns **content**.

If you use a password manager, generate **unique passwords** per platform and keep them private.
